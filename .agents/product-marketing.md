# Locus product marketing context

## Positioning

Locus gives coding agents a task-sized Slice of a JavaScript or TypeScript Repo and shows the developer why every file was Included, Excluded, or added by Widen. The product is evidence-first: it reports historical localization results and factual Run usage without claiming autonomous task success or verified token savings.

## Public stage

Locus is in **public early access**.

- Any signed-in user may localize a supported public Repo and inspect the Slice.
- Complete Agent Runs are limited to invited design partners.
- Billing, private-Repo reads, teams, external GitHub writes, and Savings claims are disabled.
- The separate Release 1 paired evaluation remains incomplete until all 40 arm results are submitted.

## Audience and actions

Primary audience: developers who use Codex, Claude Code, Cursor, or another coding agent on JavaScript or TypeScript Repos.

Primary action: **Try Repo localization** at `/workspace`.

Secondary action: **Request Agent Run access** at `/pricing`.

## Evidence that may be stated

- 100% fix-file recall on the 15 retained historical cases in the project's own regression suite.
- 53% median estimated context reduction across that suite.
- The suite covers 15 fixes across three repositories owned by the project author.
- These figures measure historical localization replay, not agent completion.

## Launch channels

- Owned: product website, access-request list, GitHub repository.
- Rented: LinkedIn first; Hacker News or Product Hunt only after the public early-access canary remains healthy.
- Borrowed: direct outreach to developers who actively use coding agents.
