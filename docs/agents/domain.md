# Domain docs

Locus uses a single-context domain layout.

Before exploring or editing domain behavior:

1. Read root `CONTEXT.md` completely.
2. Read relevant decisions under `docs/adr/`.
3. Use the exact glossary terms in `CONTEXT.md`.
4. Surface any conflict with an accepted ADR explicitly.

If a required concept is absent from the glossary, add it only when the design
actually resolves its meaning. Do not invent a synonym for an existing term.
